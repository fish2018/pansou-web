双虚线轨道 + 12 个网盘图标公转 + 呼吸缩放 + 脉冲圈 + 漂浮粒子。
**配色全部改掉**——参考站的多色轮换（淡蓝→淡粉→淡绿→淡紫）和绿蓝混搭粒子与本项目

## 实现要点

- `src/components/LoadingOrbit.vue`，替换 `App.vue` 里原来的骨架屏（5 条 `animate-pulse` 方块）。
- 12 个网盘图标沿用参考站的 SVG，放 `public/pan-icons/`——**不能放 `src/assets/`**：
  模板里的运行时路径不会被 Vite 处理，放 src 开发能跑、生产构建必然 404。
- 公转与自转在同一个 `transform` 里抵消（`rotate(θ) translateY(--r) rotate(-θ)`），图标才能严格正立；
  半径走 `--r`，移动端只改半径。
- 12 个图标各用不同呼吸周期与负相位延迟（7~13s 内互不成倍数）→ 长期永不同步，不会"排队一起变小"。
- 尊重 `prefers-reduced-motion: reduce`（参考站没有做）。

## 视觉验证方式

用组件自身的 CSS 生成静态预览页，Chrome 无头截图后逐张检查（两版：动画初态 / 冻结在各相位）。
第一次截图发现 12 个图标全部叠在中心——因为预览的"静止"覆盖把定位用的公转动画也关掉了，
图标失去 transform 后都落回中心、被中心徽标挡住。改成"只暂停不移除动画 + 徽标呼吸归零"后正常。
最终确认：双轨道、12 图标各自就位、中心蓝徽标、蓝色光晕、粒子可见、文案排版正常。
图标徽标由 42px 放大到 48px（图形占比 52%→56%）以提高品牌图形可读性。

## 修订：配色 bug 与两套等待样式（同日）

### 1. 中心徽标变成黄绿色 —— CSS 变量格式搞错

第一版把颜色写成 `rgb(var(--primary))`，渲染出来是黄绿色。原因是本项目真正引用的样式文件是
`pansou.css`，其中 `--primary: 217 91% 60%` 是 **HSL 三元组**；`rgb()` 里混入百分比后，
Chrome 按 CSS Color 4 解析成 `rgb(217, 91%, 60%)` = `rgb(217, 232, 153)`——正是截图里那个黄绿色。
（`onefour-unified.css` 里确实有 RGB 格式的同名变量，但那个文件没有被 import。）

改为 `hsl(var(--primary, 217 91% 60%))` 与 `hsl(var(--primary) / 0.16)` 这类正确写法，
中心徽标、光晕、脉冲圈、徽标描边、阴影全部回到项目主色蓝。

**为什么第一版没查出来**：本地静态预览里我手填的是 RGB 值，把变量格式差异掩盖了。
修完后预览改用 `pansou.css` 的真实变量值重新渲染核对，才真正验证到配色。

### 2. 两套等待样式合一

项目里原本有两个等待态，触发条件不同：
- `App.vue`：`v-if="loading"`，首次搜索请求在飞时；
- `ResultTabs.vue`：`showSearchingState = !hasResults && hasSearched && isActivelySearching`，
  搜索已发起但结果还没落地（含后台刷新中）时显示的是**另一套**蓝色 spinner + 「正在搜索资源中...」。

现在 `ResultTabs` 也直接用 `LoadingOrbit`，旧 spinner 与两行文案从构建产物中彻底消失
（`资源搜索可能需要一些时间` 与 `searching-spinner` 在 dist 里均为 0 次命中）。

### 3. 去掉动画下方的说明文字

按反馈移除「正在搜索「关键词」」与「正在聚合网盘插件与 TG 频道结果，请稍候」两行，
组件不再需要 `keyword` 参数。
